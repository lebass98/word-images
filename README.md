# word-images

영어 단어 학습 앱([English_word](https://github.com/lebass98/English_word))의 연상 그림 저장소.

- 5,406장 / 384px WebP / 약 67MB
- 원본은 512px PNG 이며 앱 저장소의 `assets/words/` 에 있다
- 파일 경로: `<첫 글자>/<철자>.webp` (띄어쓰기는 붙임표로: `living room` → `l/living-room.webp`)

## 받아 쓰는 법

jsDelivr CDN 으로 받는다. 판(태그)을 붙여야 그림을 바꿔도 예전 앱이 흔들리지 않는다.

```
https://cdn.jsdelivr.net/gh/lebass98/word-images@v1/a/apple.webp
```
